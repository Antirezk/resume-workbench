简历工作台 - Windows 免安装版

适用系统：Windows 10 / Windows 11，64 位。
无需安装 Python、Excel、OCR 软件或开发环境。

1. 把“简历工作台.exe”放在可写文件夹中，双击运行。
2. 程序会打开默认浏览器，并在右下角通知区域显示程序图标。
   第一次启动需要解包内置运行库，请稍等数秒。
   页面地址：http://127.0.0.1:8765
3. 在“API 设置”中选择供应商，填写模型名称和 API Key。
   程序不附带供应商密钥，调用模型需要联网并使用自己的账号。
4. 上传后自动统计支持的简历文件数量，无需选择份数或处理并发。
   每批最多 50 份；ZIP 按其中支持的简历文件数量计算。
   超过限制会在开始处理前提示，统计数量不调用模型 API。
5. 本科、硕士、博士等教育经历分别保留学校、学院、专业、学位、
   就读时间、学习形式、毕业/在读状态、研究方向和原文提供的学习详情。
   简历没有写的信息不会补造。最高教育阶段不等于已取得对应学位。
6. 工作与实习分开：每段保留公司、岗位、部门、地点、起止时间、
   时长、职责与成果。工作和实习分别累计，重叠月份去重。
   时长含首尾月，非精确天数；缺失、倒置、未来日期不计算。
   兼职、劳务和性质未明确的记录单独保留，不计入两项累计。
7. 同步记录项目角色/技术/成果、证书奖项、语言成绩、作品集、
   期望城市、求职状态、到岗时间和自述年限，仅提取原文明示内容。
8. 备注分为短备注与详细备注：短备注最多50字，直接显示在姓名
   下方，可选择常用字体颜色或自定义颜色；详细备注最多5000字，
   需点击“查看详细备注”或进入候选人详情查看，列表不展开内容。
   姓名下方的备注按钮和详情页顶部均可编辑，并有颜色实时预览。
   清空相应内容后保存即可删除。备注独立保存在本机，支持搜索，
   Excel/PDF保留两段内容与短备注颜色；重新提取或重启均保留，
   不发送到模型API。旧版备注会保留为详细备注。
9. 核对并修改候选人信息后，可以导出 11 张表的 Excel 或中文 PDF。
   旧批次点击“补全实习 / 工作信息”可再次调用模型补全。
   人工修改的已有内容保持原值，仅对匹配记录补空字段；未匹配的
   新经历请核对原文后手动添加。调用失败保留原信息。

停止程序：右键通知区域的“简历工作台”图标，选择“退出”。
关闭浏览器页面不会停止后台处理。重复双击会打开已运行的页面。

原始简历、数据库和日志保存在 EXE 旁的“简历工作台数据”文件夹。
如果 EXE 所在文件夹不可写，数据目录会改用当前用户的本地应用目录。
托盘菜单“打开数据文件夹”可以查看实际位置。
备份时保留该数据文件夹；交给另一位使用者时只复制 EXE 即可。

内置中文 OCR 模型和开源中文字体，扫描识别和导出不需要下载额外模型。
未配置 API Key 时，可以点击“查看演示数据”体验界面和导出。
API Key 仅保存在当前网页内存，刷新页面后需要重新填写。

候选人数据库：左侧点击“候选人数据库”，可管理全部真实批次。
每份真实简历成功分析后自动入库；先分析3份，再分析1份新的简历，
数据库就有4条记录。已有成功结果会自动纳入；失败、等待、演示
数据不入库，同一条记录重新提取会更新原记录，不重复增加数量。
不同批次的简历版本分别保存，相同联系方式会提示核对。
支持搜索、学历筛选、分页、手动新增、完整资料与两段备注编辑。
删除候选人移到回收站，可恢复；删除批次不会删除已入库的信息。
数据库中修改资料会同步到仍存在的原批次，手动维护无需模型API。
导出包含当前筛选的全部分页；备份请保留整个“简历工作台数据”
文件夹，数据库具体保存位置可在页面底部查看。
